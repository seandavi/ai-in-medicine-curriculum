# AI in Medicine — Curriculum

A modular, competency-based 4-week elective on AI in medicine for fourth-year
medical students. ~40 students, Zoom-only, ungraded.

- `curriculum/` — the curriculum itself: competencies, module descriptions, week-by-week schedule
- `modules/` — one directory per module (core + enrichment), each self-contained
- `research/` — background research reports informing the design
- Existing talk materials live in the sibling [seandavi/talks](https://github.com/seandavi/talks) repo (`../talks`)
